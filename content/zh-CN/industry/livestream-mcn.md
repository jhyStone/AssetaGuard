## TL;DR

MCN 直播间的核心痛点是**直播设备和样品流转混乱、达人借用不归还、耗材物资进出对不上账**。AssetaGuard 把直播间的物品分两条线管：**资产**（直播设备、展示样品、道具等可复用物品）贴 RFID 标签，逐件追踪；**物资**（包装、赠品、耗材）按出入库记录，月度对账。资产 500 件 5 秒盘完，损耗率从 8% 压到 0.3% 以内。

## 先把"资产"和"物资"分清楚

直播间里所有东西不是都要贴 RFID，否则成本和工作量都不划算。AssetaGuard 按"是否需要逐件追踪"区分：

| 类型 | 范围举例 | 管理方式 | 是否贴 RFID |
| --- | --- | --- | --- |
| **资产** | 摄像机、补光灯、监视器、提词器、电脑、麦克风、上播样品、道具、服装 | 一物一码，逐件登记借用 / 归还 / 盘点 | ✅ 是 |
| **物资** | 包装盒、快递袋、赠品小卡、化妆棉、清洁耗材 | 按 SKU 记录出入库数量，月度盘存 | ❌ 否（按账管） |

资产解决"谁拿走了、什么时候还、有没有丢"；物资解决"领了多少、用了多少、还剩多少"。两条线在同一个系统里看，但操作方式和成本完全不一样。

## 落地的 8 个动作

### 1. 资产入库即贴标
设备 / 样品到仓 → RFID 手持机扫供应商单 → 自动绑定标签 ID → 录入 SKU、批次、供应商。新员工 30 分钟会用。

### 2. 资产扫描识别 = 一扫就知道这是什么
手持机扫到任意 RFID 标签 → 立即显示完整资产卡：名称、规格、责任人、当前位置、借用历史。
- 仓库捡到一件不知道是谁借的样品：扫一下立刻有主
- 退货回仓核对：扫码立刻看到当初发货单据

### 3. 寻物模式（盖革计数器式定位）
知道编号但不知道样品在哪？手持机切到**寻物模式**，输入目标标签 → 按 RFID 信号强弱实时反馈（信号越强离目标越近）找到那一件。
- 上播前急用某件样品找不到：30 秒在堆里定位
- 达人借走没还，怀疑还在仓里某处：缩小搜索范围

### 4. 达人借用 = 一次扫描
达人选样 / 借设备 → 手持机一过 → 系统自动生成借用单（含图片、归还时限），登记到达人个人名下。**到期未归还，系统自动产生未归还告警**，推送给仓管和主管处理（系统不做自动短信 / 小程序催还，催还动作由管理流程负责）。

### 5. 直播退换货核对
退货回仓 → 手持机贴近箱体 5 秒读完 → 系统自动比对发货清单 → 缺件 / 错件 / 假货（无标签 / 标签 ID 不匹配）当场报警。

### 6. 资产月度全盘
RFID 手持机沿货架走一圈，1000 件资产 30 秒读完 → 系统自动出差异表 → 责任到人（最近一次借用 / 出库人）。

### 7. 物资按账记录
耗材入库、领用、退库直接在系统里走单据，按 SKU 累计；月度做一次实物盘存，差异在系统里写明原因。不贴 RFID，但和资产共用一套权限、报表和审批。

### 8. 资产全生命周期管理（状态 / 维护 / 报废）
直播间的摄像机、补光灯、提词器这些设备资产，乃至样品本身都有生命周期。AssetaGuard 把全程记录串起来：

- **状态变更**：在用 / 闲置 / 维修 / 报废 四态切换，每次变更记录操作人 + 时间戳，避免"这个灯到底坏没坏"扯皮
- **维护 / 维修记录**：直播设备送修、达人服装清洗送返修都可以手工登记，挂在资产详情页
- **生命周期视图**：入库 → 达人借用历史 → 维护记录 → 报废 / 退还供应商，一条时间线，达人结算 / 供应商对账都好查
- **报废 / 处置流程**：样品过季、设备损坏走报废单 → 主管审批 → 从在用资产池移出

## 常见问题

**Q: 我们用了 ERP，还要这套系统吗？**
ERP 管"账"，AssetaGuard 管"物"——尤其是资产逐件的去向。两边可以打通（用友、金蝶、自研系统），不替换 ERP。

**Q: 达人借用不归还，系统能强制吗？**
系统不能"强制"，但**到期未归还会自动产生未归还告警**，按规则升级提醒仓管和主管。AssetaGuard 把"谁、什么时候、借了什么、还没还"写得清清楚楚，催还动作仍由管理流程执行，但扯皮空间压到零。

**Q: 包装、赠品这种小东西也要贴 RFID 吗？**
不需要。这类属于"物资"，在系统里按 SKU 记录出入库数量即可。只有需要逐件追踪去向的资产（设备、样品、道具）才贴 RFID。

**Q: RFID 标签贵不贵？**
柔性标签 0.3–0.8 元/枚，金属标签 1–3 元/枚。一件衣服样品价值 200–2000 元、一台补光灯几百到几千，标签成本可忽略。
