## TL;DR

制造业车间的"找不到、对不上、追不到责任"三大痛点，本质是**资产移动太快、记录跟不上**。AssetaGuard 给每件工装、模具、设备贴 RFID 标签，借用归还走手持机扫码登记到个人名下，月度盘点 1000 件 30 秒读完，盘亏率从 5% 压到 0.3%。固定通道闸、设备点检 SOP、保养周期提醒等深度场景在产品路线图中分阶段落地。

> ⚠️ **当前能力说明**：本方案的"已落地能力"已在直播 MCN 行业首发案例中跑通；制造业专属深度场景（通道闸、点检 SOP、保养提醒）在下方"产品路线图"章节列出，欢迎试点客户一起共建。

## 先把"资产"和"物资"分清楚

车间里所有东西不是都要贴 RFID，否则成本和工作量都不划算。AssetaGuard 按"是否需要逐件追踪"区分：

| 类型 | 范围举例 | 管理方式 | 是否贴 RFID |
| --- | --- | --- | --- |
| **资产** | 工装夹具、模具、检具量具、电动工具、便携设备、固定大型设备 | 一物一码，逐件登记借用 / 归还 / 盘点 | ✅ 是 |
| **物资** | 螺丝、垫片、砂纸、切削液、棉纱、清洁耗材 | 按 SKU 记录出入库数量，月度盘存 | ❌ 否（按账管） |

资产解决"谁拿走了、在哪、什么时候还、有没有丢"；物资解决"领了多少、用了多少、还剩多少"。两条线在同一个系统里看，但操作和成本完全不一样。

## 制造业车间的 4 类资产管理痛点

| 资产类型 | 典型痛点 | 业务损失 |
| --- | --- | --- |
| 工装夹具 | 借出不归还、丢了不知道谁用过 | 单套模具 5–50 万元，年损失数十万 |
| 检具 / 量具 | 校准周期靠 Excel 提醒，超期使用 | 质量风险、客户审核扣分 |
| 便携 / 大型设备 | 移机不记录，固定资产盘点对不上 | 月底差异 5%–10% 当损耗冲掉 |
| 耗材物资 | 纸质领料单 / 群里报 | 账面与实物差距大 |

## 已落地能力（直播 MCN 案例已验证）

### 1. 资产入库即贴标
工装 / 模具 / 设备到位 → RFID 手持机扫供应商单 → 自动绑定标签 ID → 录入 SKU、批次、供应商、所属车间。新员工 30 分钟会用。

### 2. 资产扫描识别 = 一扫就知道这是什么
手持机扫到任意 RFID 标签 → 立即显示完整资产卡：名称、规格型号、责任人、当前位置、借用历史、维护记录。  
- 捡到一件无主工装：扫一下立刻知道是哪个班组的
- 设备移机后核对身份：不用查台账
- 物料员交接班：扫码点验，0 误差

### 3. 寻物模式（盖革计数器式定位）
知道资产编号但不知道在哪？手持机切到**寻物模式**，输入目标标签 → 按 RFID 信号强弱实时反馈（信号越强离目标越近），像盖革计数器一样找到那一件。  
- 找堆里的特定工装：30 秒搞定
- 找被借走但忘了登记的设备：缩小搜索范围
- 适合工装架混放、货架深处、车间散落场景

### 4. 工装夹具借用 = 一次扫描
工装室出入口或工位旁 → 手持机扫资产标签 + 工卡 → 系统自动生成借用单（含图片、归还时限），登记到个人名下。**到期未归还，系统自动产生未归还告警**，推送给工装管理员和班组长。
- 工装找件从 30 分钟降到 30 秒
- 借用人、归还时间、当前位置一目了然

### 5. 资产月度全盘
RFID 手持机沿货架 / 工位走一圈，1000 件资产 30 秒读完 → 系统自动出差异表 → 责任到人（最近一次借用 / 出库人）。

### 6. 物资按账记录
耗材入库、领用、退库直接在系统里走单据，按 SKU 累计；月度做一次实物盘存，差异在系统里写明原因。不贴 RFID，但和资产共用一套权限、报表和审批。

### 7. 资产全生命周期管理（状态 / 维护 / 报废）
RFID 标签不是贴上就完事，资产从入库到报废全程在系统里留痕：

- **状态变更**：在用 / 闲置 / 维修 / 报废 四态切换，每次变更记录操作人 + 时间戳，避免"工装到底在不在用"扯皮
- **维护 / 维修记录**：手工登记维修内容、维修人、费用、出厂日期 / 模次等关键字段，全部挂在资产详情页
- **生命周期视图**：入库 → 借用归还历史 → 维护记录 → 报废，一条时间线串起来，资产档案随时可查
- **报废 / 处置流程**：资产到期或损坏走报废单 → 主管审批 → 从在用资产池移出，标签可回收复用或归档

## 离线工况怎么办？

车间常见弱网 / 无网工位，AssetaGuard 移动端原生支持**在线 / 离线双模式**：
- 离线时本地缓存全部任务和资产数据
- 网络恢复后增量上传，幂等键去重，零数据丢失
- 适合地下车间、偏远厂区、车间金属屏蔽环境

### 🛣️ R2. 设备点检 SOP + 工单闭环
设备贴 RFID → 点检员手持机扫码 → 自动加载 SOP 检查项 → 缺漏项无法签收 → 异常项自动派单维修。  
依赖：SOP 表单引擎 + 维修工单模块。

### 🛣️ R3. 抗金属标签 + 高温环境贴标实战包
铸造 / 焊接 / 热处理车间专用抗金属、抗高温标签选型与贴标 SOP。  
依赖：硬件适配验证 + 现场工艺落地手册。

### 🛣️ R4. 保养周期自动提醒
设备 / 工装按预设保养周期（按时间 / 按使用次数 / 按模次）到期 → 系统自动弹待办 + 告警 → 提醒责任人执行保养。  
依赖：周期规则引擎 + 待办推送机制。

### 🛣️ R5. 维修工单流转（报修 → 分派 → 处理 → 验收）
现场扫码报修 → 工单自动分派给维修组 → 处理过程留痕 → 验收闭环。多角色工单协作。  
依赖：工单引擎 + 多角色权限模型。

### 🛣️ R6. 设备运行数据 / IoT 集成
采集设备运行时长、开关机状态、报警信号 → 结合 RFID 资产档案推送预测性维护建议。  
依赖：IoT 网关适配 + 时序数据存储。

## 常见问题

**Q: 金属环境 RFID 不是会失效吗？**
普通柔性标签贴在金属表面会失效，需要换**抗金属标签**（陶瓷 / FR4 基板）。具体读距和稳定性要按车间环境实测——这部分硬件适配在路线图 R4 中作为专项推进。

**Q: 现有 ERP 系统能集成吗？**
能。AssetaGuard 走标准 REST API + 离线 CSV 导入/导出，与 ERP（用友 / 金蝶 / 自研）做账物对齐，不替换 ERP。MES 实时集成不在当前规划范围内，如有强需求请单独沟通定制。

**Q: 工装借出不归还，系统能强制吗？**
系统不能"强制"，但**到期未归还会自动产生未归还告警**，按规则升级提醒工装管理员和班组长。AssetaGuard 把"谁、什么时候、借了什么、还没还"写得清清楚楚，催还动作仍由管理流程执行，但扯皮空间压到零。

**Q: 螺丝、垫片这种小耗材也要贴 RFID 吗？**
不需要。这类属于"物资"，在系统里按 SKU 记录出入库数量即可。只有需要逐件追踪去向的资产（工装、模具、设备）才贴 RFID。

**Q: 几百台设备 + 几千件工装，初期投入多大？**
按 1000 件资产估算：标签 2000–5000 元 + 手持机 3000–8000 元/台（按需配） + AssetaGuard 订阅按月付。试点期 < 1 万元启动。
