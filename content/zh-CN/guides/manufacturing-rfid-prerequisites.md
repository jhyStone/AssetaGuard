## 4 个核心前置条件（必备）

### 前置 1：资产基线必须先盘清

最常见的失败模式：系统上线发现实际工装比账面少 30%。**RFID 不是用来"找回"丢的工装的，是用来"以后不再丢"的**。先用 1–2 周做一次彻底人工盘点，把基线对齐再上 RFID。

### 前置 2：资产 vs 物资 分清楚

不是所有东西都要贴 RFID：

| 类型 | 范围举例 | 管理方式 | 是否贴 RFID |
| --- | --- | --- | --- |
| **资产** | 工装夹具、模具、检具量具、电动工具、便携 / 大型设备 | 逐件登记借用 / 归还 / 盘点 | ✅ 是 |
| **物资** | 螺丝、垫片、砂纸、切削液、棉纱 | 按 SKU 记录出入库数量 | ❌ 否（按账管） |

资产数 + 物资 SKU 都要先梳理清单，再决定标签数量与系统配置。

### 前置 3：ERP 接口可用

AssetaGuard 与 ERP 走**标准 REST API + CSV 导入导出**做账物对齐，不替换 ERP：

| ERP 系统 | 集成难度 |
| --- | --- |
| 用友 / 金蝶（标准接口） | 1–2 周 |
| 自研 ERP | 看接口情况，2–4 周 |
| 完全没有 ERP | AssetaGuard 自带轻量资产 + 物资台账，先用着 |

⚠️ **MES 实时集成不在当前规划范围内**，如有强需求请单独沟通定制。

### 前置 4：操作工配合机制

技术不是难点，**人不配合系统就跑不动**。建议：
- 培训：每个工人 30 分钟，操作非常简单（手持机扫一下）
- 流程绑定：借用归还动作与工卡 / 班组绩效挂钩，自然就配合了
- 不让工人手工"补录" —— 数据立刻造假

## 推荐前置（非必备但有助于落地顺利）

### 推荐 1：试点产线 / 试点车间选定

不要一次铺全厂。先 1 条产线 / 1 个工装室试点 2 周，再评估全厂铺开节奏。

### 推荐 2：弱网工位评估

车间常见弱网 / 无网工位（地下车间、金属屏蔽工位、偏远厂区）。AssetaGuard 移动端原生支持**在线 / 离线双模式**，离线缓存 + 网络恢复后自动同步，所以"没网"不是阻塞条件，但提前知道哪些工位是离线场景，便于规划同步时机。

## 不需要的前置

- **不需要换 ERP**：AssetaGuard 与现有 ERP 集成，不替代
- **不需要 MES 现成**：如果想做 WIP 工序追踪 / MES 集成，那是路线图方向（详见[《工厂在制品与 MES 集成的 RFID 应用探索》](/blog/2026-05-manufacturing-wip-rfid)），但**工装借用 + 资产盘点 + 物资台账**这些已落地能力不依赖 MES
- **不需要全厂一次铺开**：先 1 条产线试点，2 周内见数据
- **不需要 IT 团队 5 人 +**：1 人对接 + 我们派一名实施工程师就够

## 路线图能力的额外前置（如果你想做深度场景）

如果你的目标不止"工装借用 + 月度盘点"，还要做工位通道闸自动报工 / MES 实时集成 / 设备点检 SOP / 校准提醒，请额外评估：

| 路线图能力 | 额外前置 |
| --- | --- |
| WIP 工位通道闸 | 工艺路线 3 个月内稳定 + 通道布点设计 |
| MES 实时集成 | MES 系统有 API + 双方 IT 团队投入 |
| 设备点检 SOP | SOP 表单引擎需求工作坊 |
| 校准 / 保养提醒 | 校准 / 保养周期主数据梳理 |
| 抗金属 / 高温标签 | 现场环境实测与标签选型 |

这些场景属于**产品共建方向**，AssetaGuard 与首批制造业试点客户一起设计落地。

## 准备好之后的节奏

| 周 | 关键里程碑 |
| --- | --- |
| W1 | 资产基线 + 物资 SKU + 标签选型 |
| W2 | 第一批贴标 + 操作工培训 + 试点产线跑通 |
| W3 | 数据对比 + 决定全厂推广节奏 |

第 2 周末通常可以看到工装找件耗时与月度盘亏的明显改善。
